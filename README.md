# Mental Health 1D CNN (NeuroTone Labs)

A **1D Convolutional Neural Network (CNN)** designed to classify mental health status into four categories:

- Healthy
- Mild Stress
- Moderate Stress
- Severe Stress

The model uses **21 input features**, consisting of 3 scores and 18 behavioural and physiological signals.

## Features

- Train the 1D CNN model using a CSV dataset.
- Predict mental health status using a selected row from the dataset.
- Classify predictions into four stress levels.
- Save and load the trained model for future predictions.

## Project Purpose

This project explores the use of machine learning and behavioural and physiological data to identify potential indicators of stress.

## Disclaimer

This is an experimental machine learning project developed for educational and research purposes. It is **not a clinical diagnostic tool** and should not replace professional mental health assessment.
